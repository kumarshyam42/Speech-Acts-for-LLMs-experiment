# h5 — Auditability asymmetry

**Tier 2 · Status: proposed** (one exemplar verified; B′ breach extraction unmeasured).
Charter: `../260706-new-hypotheses.md` §H-N5.

**Claim.** Metrics like "declared-then-ignored," "mislabeled act," and "scope violation" are
only *computable* for B, because only B's declarations are typed objects. B′ committed the
same sin invisibly. The protocol's value includes making its own failures countable — H0 was
only confirmable *because of* the structure it indicts, and A/B′'s equivalent events are
simply dark.

**Motivating data (verified).**
- `runs/rep1/t02-Bp` first assistant message: "'Sluggish' is subjective — I'll profile/measure
  to find the actual bottleneck rather than guessing. ... **Success**: The report command runs
  measurably faster with the same output." Judge verdict: fail; no measurement was ever taken.
  A declared-then-ignored event, invisible to mechanical scoring because it is prose.
- The H0 ledger's B-only metrics (`cos_declared_ignored`, `report_schema_missing`,
  `protocol_error`) have no A/B′ analogue by construction.

**Layer.** Measurement/system — meta-level, but load-bearing for the paper's §6.2 reframe
("fails transparently vs fails opaquely").
**Pi connection.** Directly supports the reframed design claim: similar failure rates, but B's
breaches are enumerable, attributable, and trust-relevant. Also the honest counter to "H0
events make B look bad."

**Planned measurement (Phase 2, judged, costly).**
Extract implied commitments from all 54 B′ deliberations (and A pushback where present) and
count ignored ones — the hidden baseline that makes the asymmetry quantitative. Rubric to
`rubric.md` + `spec/decisions-log.md` first; verdicts to `verdicts/`. The structural asymmetry
itself is an argument, not a test.

**Credibility path.** Depends entirely on the new instrument; report per-class. Candidate for
deferral to the future run if Phase-2 budget is tight — the argument stands without the count,
the count just makes it quantitative.
